# PillPal - Smart Medicine Dispenser

## Overview

Welcome to **PillPal**, a smart medicine dispenser designed to assist with medication management. This project integrates hardware and software to provide a reliable solution for dispensing medication on schedule and monitoring patient adherence.

## Features

- **3D Mechanical Design**: Custom enclosure and dispensing mechanism designed using SolidWorks.
- **Mobile Application**: A Flutter-based app for setting medication schedules and receiving reminders.
- **Real-Time Monitoring**: Utilizes ESP32 and Firebase to track dispensing and patient usage.
- **Firmware Development**: C++ firmware for controlling the ESP32 and managing the dispensing process.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Achi-456/Pillpal.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Pillpal
   ```

3. Install the required dependencies (detailed in `requirements.txt` if provided).
4. Set up the Firebase configuration and ESP32 development environment.
5. Build and flash the firmware to the ESP32 device.

## Usage

- Configure the medication schedule via the Flutter app.
- Connect the ESP32 to the app and Firebase for real-time updates.
- The dispenser will automatically release medication at scheduled times.
